# Telegram-бот

Простой Telegram-бот на Python с меню для получения курсов криптовалют, генерации случайных значений и просмотра времени в городах России.

## Возможности

После запуска команды `/start` бот показывает главное меню:

- **Курсы валют** — отображение текущей цены BTC, ETH, LTC, TON и TRX в рублях и долларах.
- **Рандомайзер**:
  - случайное число от 0 до 100;
  - имитация броска игральной кости;
  - генерация случайного пароля длиной 8 символов.
- **Время** — отображение времени в различных часовых поясах России: Калининград, Москва, Самара, Екатеринбург, Омск, Красноярск, Иркутск, Якутия, Владивосток, Магадан и Камчатка.

Курсы криптовалют загружаются через API биржи YoBit.

## Требования

- Python 3.8 или новее
- Telegram-аккаунт
- Telegram-бот, созданный через [@BotFather](https://t.me/BotFather)
- Доступ к интернету для получения курсов валют и работы с Telegram API

## Установка

1. Клонируй репозиторий и перейди в его каталог:

   ```bash
   git clone <URL-РЕПОЗИТОРИЯ>
   cd telegrambot
   ```

2. Создай виртуальное окружение:

   ```bash
   python -m venv .venv
   ```

3. Активируй виртуальное окружение.

   **Windows:**

   ```bash
   .venv\Scripts\activate
   ```

   **Linux/macOS:**

   ```bash
   source .venv/bin/activate
   ```

4. Установи зависимости:

   ```bash
   pip install pyTelegramBotAPI requests
   ```

## Настройка токена

В корне проекта создай файл `auth_data.py`:

```python
token = "ТОКЕН_ТЕЛЕГРАМ_БОТА"
```

Токен можно получить у [@BotFather](https://t.me/BotFather) после создания бота.

Файл `auth_data.py` добавлен в `.gitignore`, поэтому его не следует публиковать в репозитории. Если токен стал доступен посторонним, отзови его через BotFather и выпусти новый.

## Запуск

Запусти бота командой:

```bash
python run.py
```

После успешного запуска открой бота в Telegram и отправь команду `/start`.

## Примечания

- Бот работает в режиме long polling.
- Для получения курсов используются публичные endpoints YoBit.
- Если API курсов недоступно или возвращает неожиданный ответ, бот отправляет сообщение об ошибке.
- Время рассчитывается относительно локального времени машины, на которой запущен бот.
